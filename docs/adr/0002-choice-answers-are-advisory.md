# 0002: 选择题/判断题只显示，不自动作答

## 状态

已接受（Phase 1）。

## 背景

FuckRank 现有能力是把代码逐字打进编辑器。选择题和判断题在题目平台中通常是单选按钮、复选框或可点击文本，不是自由文本输入框。

自动选中需要：

- 坐标点击或 UI Automation，和浏览器/页面布局强耦合；
- 在目标窗口产生鼠标移动、焦点切换、滚动或提交动作，显眼且脆弱；
- 额外的错误处理：点错、页面未加载、选项顺序变化、滚动位置变化。

用户的目标是“看到答案后自己选”，不是让工具代考。

## 决定

Phase 1 的选择题/判断题答案只显示在托盘答案行。工具不点击、不选中、不提交，也不把选项字母打进编辑器。

代码题仍保留原来的自动打字行为。

在 READY 且持有选择题/判断题答案时，第二次热键是“重新请求”，不是“输出答案”。

## 后果

- 用户手动完成选择；工具不感知选择结果。
- 不新增 State；选择题不会进入 TYPING。
- 托盘是唯一答案面；没有 HUD、通知或第二个窗口。
- 如果将来要自动选中，需要单独设计 UIA/坐标适配和显式开关，不在 Phase 1 范围内。
