# 0001: 托盘答案点行（Tray answer dot row）

## 状态

已接受（Phase 1，V7）；2×2 点版本由 #3 返工。

## 背景

FuckRank 现有托盘图标是 16px 灰蓝云朵 + 右下角彩色状态点。Phase 1 需要在不引入 HUD、窗口或通知的前提下，显示单选题和判断题答案。

隔壁项目 fPTA 采用整块浅色圆角“芯片” + 四角 LED + 中心标记。该方案可读，但不适合直接照搬：

- 整块浅色芯片面积大、亮度高，和 FuckRank 的云朵图标差异过大；
- 四角 LED 的视觉语言容易被认成同一产品的变体；
- FuckRank 的隐蔽要求是“小面积、低饱和、看起来像普通后台应用”，不是整块高对比芯片。

还考虑过：

- 在徽标里写 A/B/C/D：16px 字体渲染差，且字母最直白，不满足隐蔽要求。
- 2×2 徽标网格：可读，但更像一个 UI 面板，且和 fPTA 的角落插槽语言接近。
- 5/6 点行：16px 下点太密，会顶到云朵边缘；六点放不下。
- 第一版 2×2 深石板点：实际使用不可读，选中点太小且颜色不跳。
- V5 选中点加白描边/放大：可读，但高亮点尺寸和空位不一致，不符合“只变颜色、不变大小”。

## 决定

保留云朵主体，只增加“答案行”：

- **单选题**：一行四个 3×3 px 点，位置 `x = 1, 5, 9, 13`，`y = 10..12`。
  - 空位：深石板灰 `#475569`。
  - 选中：亮绿 `#22C55E`。
  - 选中点和空位点尺寸完全一致，不加白描边、不放大。
- **判断题**：两个 5×5 px 点，位置 `x = 3..7`、`x = 8..12`，`y = 9..13`。
  - 左 = 正确/对，右 = 错误/错。
  - 空位/选中同上；选中点不放大。
- 答案行显示时隐藏右下角状态点；其他状态仍显示原状态点。
- 只支持单选题的 A–D。多选题、5 个以上选项、E/F 选项全部按软失败处理，不猜测答案。
- 不使用字母、动画、每选项颜色、白色底板。

## 后果

- 16px 下可读性依赖亮绿选中点与深色空位的颜色差；README 和 spec 必须教用户“四点 = 单选、两点 = 判断、左对右错”。
- 浅色/深色任务栏、100–200% DPI 需要手动验收。
- 图标彩色面积仍然很小；选中点只占 3×3 或 5×5。
- 答案行与状态点互斥；用户在看到答案时不再看到 READY 绿点。
- 多选题在 Phase 1 没有答案交付路径；这是明确的非目标。
