# C语言题目后台助手

后台常驻桌面小工具，全局快捷键触发，托盘图标反馈状态和单选题/判断题答案，AI 辅助生成 C 语言答案。

## 部署

```powershell
# 1. 克隆
git clone https://github.com/HermosMerlin/FuckRank.git
cd FuckRank

# 2. 创建虚拟环境并安装依赖
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"

# 3. 第一次运行会自动生成 config.json，编辑填入你的 api_key
notepad config.json

# 可选：在 config.json 中设置 "typing_mode": "auto" 切换为自动打字模式
```

## 使用

```powershell
# 前台运行（看日志）
.\run.bat

# 后台静默运行
.\start-hidden.vbs
```

### 状态机与快捷键

托盘图标右下角的彩色圆点实时显示系统状态：

| 颜色 | 状态 | 含义 |
|------|------|------|
| 🟢 绿色 | **READY** | 系统就绪，可以按快捷键触发 |
| 🟡 黄色 | **REQUESTING** | 正在读取剪贴板并向 AI 请求答案 |
| 🔵 蓝色 | **TYPING** | 正在模拟键盘逐字输出答案 |
| 🔴 红色 | **ERROR** | API 连接失败，10 秒后自动重试 |
| ⚫ 灰色 | **IDLE** | 启动中或重试中，正在检测 API |

**按 `Ctrl+Alt+G` 开始请求：代码题需要第二次热键输出，单选题/判断题直接看托盘答案。**

### 单选题 / 判断题（Phase 1）

托盘图标除了右下角状态点，还能在云朵下部（靠近底边）显示一行答案点：

| 图案 | 含义 |
|------|------|
| 四点，第 1 个亮绿 | 单选 A |
| 四点，第 2 个亮绿 | 单选 B |
| 四点，第 3 个亮绿 | 单选 C |
| 四点，第 4 个亮绿 | 单选 D |
| 两点，左亮右灰 | 判断：正确 |
| 两点，左灰右亮 | 判断：错误 |

- **深灰点是空位**：四点 = 单选题，两点 = 判断题；空位让题型和选项位置一眼可辨。
- **只变颜色，不变大小**：选中点是亮绿，空位是深灰，两者尺寸完全一致，没有放大或白描边。
- **只显示，不自动点选**：工具不会点击选项、不会提交，也不会把答案打进编辑器；请自己在题目界面选择。
- **换题**：复制新题，再按一次 `Ctrl+Alt+G`。单选题/判断题状态下，第二次热键是“重新请求”，不会打字。
- **代码题不变**：第一次请求，第二次输出代码。
- **只支持单选题的 A–D**：多选题和 5 个以上选项 Phase 1 不支持，图标会保持 🟢 绿色就绪点并记录日志。
- **答案显示时状态点隐藏**：答案行本身就是“已就绪”的信号。
- 托盘 tooltip 固定为 `C Helper — Ctrl+Alt+G`，不包含答案。

### 手动打字模式 (manual mode，仅代码题)

代码题默认使用**手动打字模式**（`"typing_mode": "manual"`）：按第二次快捷键进入手动输出会话，每按一次 a-z 字母键，屏幕上输出答案的下一个字符（而非你按的字母），你掌控打字节奏。单选题/判断题不会进入这个模式。

- **进入手动打字会话**：等圆点变回 🟢 绿色后，按第二次 `Ctrl+Alt+G`，托盘变为 🔵 蓝色（TYPING）
- **逐字输出**：每按一次 a-z 字母键，屏幕上输出答案的下一个字符（而非你按的字母），你掌控打字节奏
- **提前结束**：按 `ESC` 键提前结束本次输出
- **自动结束**：答案全部播完后自动结束，回到 🟢 绿色
- **非字母键正常透传**：Backspace、空格、数字、标点、方向键等非字母键正常透传给编辑器，可正常编辑
- **状态复用**：手动模式复用 TYPING（蓝色）状态，不新增状态

如果不需要自己掌控节奏，可以在 `config.json` 中设置 `"typing_mode": "auto"` 切换为自动打字模式，按第二次快捷键后系统自动逐字输出答案（带随机延迟模拟人类打字）。

### 典型操作流程

#### 代码题

1. **把题目复制到剪贴板**（Ctrl+C）
2. **按一次 `Ctrl+Alt+G`** → 状态变为 🟡 黄色（请求中）
   - 系统自动：读取剪贴板 → 发送给 AI → 等待返回 → 缓存答案
   - 完成后自动回到 🟢 绿色（就绪）
3. **等圆点变回绿色后，再按一次 `Ctrl+Alt+G`** → 状态变为 🔵 蓝色（输出中）
   - **手动模式（默认）**：每按一次 a-z 字母键输出答案的下一个字符，按 `ESC` 提前结束
   - **自动模式**：系统以打字机效果逐字输入到当前光标位置
   - 完成后自动回到 🟢 绿色（就绪）

> 💡 **为什么需要按两次？** 第一次是"问 AI"，第二次是"把答案打出来"。你也可以在步骤 2 之后先去别的地方，过一会儿再回来按第二次快捷键输出答案——答案会缓存在本地，不会丢失。

#### 单选题 / 判断题

1. **把题目复制到剪贴板**（Ctrl+C）
2. **按一次 `Ctrl+Alt+G`** → 🟡 黄色（请求中）
3. **等托盘出现答案行**：四点看选项位置，两点看左对右错；然后自己在题目界面选择
4. **换题**：复制新题，再按一次 `Ctrl+Alt+G`；不会进入打字模式

> 💡 单选题/判断题只需要一次请求；第二次热键是"重新请求"，不是"输出答案"。

### 注意事项

- **黄色/蓝色状态下按快捷键会被忽略**：防止在请求或输出过程中误触导致中断。
- **红色状态下按快捷键无效**：系统正在自动重试连接 API，10 秒后会自动恢复。
- **单选题/判断题不会自动点选或提交**：工具只显示答案，选择由你完成。
- **单选题/判断题不会打字**：第二次热键是重新请求；只有代码题会进入蓝色 TYPING 状态。
- **答案行显示时右下角状态点隐藏**：看到四点或两点就表示答案已就绪。
- **只支持单选题 A–D**：多选题和 5 个以上选项会保持 🟢 绿色就绪点并记录日志，不显示猜测答案。
- **模型没按格式返回时**：托盘保持 🟢 绿色就绪点，不会把答案文本打进编辑器；再按一次 `Ctrl+Alt+G` 重试。
- **强制重置**：如果卡住了，右键托盘图标选择"强制重置为空闲"，系统会立即回到灰色重新检测 API，并清除当前答案。
- **托盘右键可退出**。
